# Open-Meteo Weather App

Вебзастосунок на Python, Flask та SQLite для пошуку поточної погоди через публічний API **Open-Meteo**, збереження спостережень у локальну базу даних та керування ними через вебінтерфейс і власний REST API.

## Основні можливості
- Пошук локацій та поточної погоди через Open-Meteo Geocoding API та Forecast API.
- Перетворення JSON-відповіді у внутрішню структуру з виведенням міста, країни, координат, температури, вологості, швидкості вітру та стану погоди.
- Збереження записів у локальну базу даних SQLite (`weather_app.db`), локальний пошук та фільтрація за містом і мінімальною температурою засобами SQL (параметризовані запити).
- Редагування та видалення збережених записів.
- Власний REST API у форматі JSON:
  - `GET /api/forecasts` — список записів (підтримує параметри `city`, `min_temp`)
  - `GET /api/forecasts/<id>` — отримання запису за ID
  - `POST /api/forecasts` — створення нового запису
  - `PATCH /api/forecasts/<id>` — часткове оновлення запису
  - `DELETE /api/forecasts/<id>` — видалення запису
